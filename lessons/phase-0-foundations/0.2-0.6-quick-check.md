# Lessons 0.2 to 0.6: Quick check

You already know the basic commands, so instead of full lessons we do one question per lesson.
Each question targets the trap that catches most people.
Right answer → lesson done. Wrong answer → we teach only that part.

| Lesson | Topic | Question |
|---|---|---|
| 0.2 | Files | `rm myfolder` fails, but `rm -r myfolder` works. Why? |
| 0.3 | Pipes and redirects | What's the difference between `>` and `>>`? |
| 0.4 | Permissions | What does `chmod 755 deploy.sh` mean, digit by digit? |
| 0.5 | Processes | What's the difference between `kill 1234` and `kill -9 1234`? When would you use `-9`? |
| 0.6 | Environment | What is `PATH`, and why do you sometimes get `command not found` for a tool you just installed? |
